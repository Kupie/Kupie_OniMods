# List of Mods
|**Mod**|**Description**|
|---|---|
|BuildOverlappingBuildings *(unreleased)*|Hold a configurable hotkey to bypass the "location is occupied" warning and place buildings that would otherwise overlap.|
|HideUIButtons *(unreleased)*|Optionally hide individual bottom-bar tool buttons (Dig, Cancel, Deconstruct, Prioritize, and more) for players who use hotkeys and don't need them onscreen.|
